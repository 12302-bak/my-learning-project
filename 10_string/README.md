
* ## 注意事项

    1. 字符串写成数组的形式，是非常麻烦的。C 语言提供了一种简写法，双引号之中的字符，会被自动视为字符数组。
    2. 即使双引号里面只有一个字符（比如"a"），也依然被处理成字符串（存储为 2 个字节 {'a','\0'} ），而不是字符'a'（存储为 1 个字节）。
    3. 字符指针和字符数组，这两种声明字符串变量的写法基本是等价的，但是有两个差异。
        * 第一个差异是，指针指向的常量字符串，不能修改字符串本身。[原因是系统会将字符串的字面量保存在内存的常量区]，而数组是新分配的内存，可以修改。
        * 第二个差异是，指针可以重新赋值，数组名不可以的，一旦为数组变量分配地址后，这个地址就绑定这个数组变量了。[可能为了便于管理或者性能之类的]
    4. 字符串数组

        ```c
        // 一维数组中保存的是 char[10]， 所以 weekdays110[3] = "hello"; ❌，但是可以通过指针去修改内容，因为是在新分配的内存中。
        char weekdays110[][10] = {
            "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"
        };

        // 一维数组中保存的是 char *，   所以 weekdays111[3] = "world"; ✅，不可修改内容，因为常量字符串在常量区中。
        char *weekdays111[] = {
            "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"
        };
        ```
